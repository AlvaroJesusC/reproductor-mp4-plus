# Reglas y Estándares para Antigravity AI en reproductormp4

Consulta las directrices completas y obligatorias en [AGENTS.md](file:///C:/Users/AlvaroJ/Documents/AndroidProjects/reproductormp4/AGENTS.md).

Este proyecto cuenta con skills especializadas instaladas en `.agent/skills/`.
Siempre que el usuario pida crear, optimizar o modificar código:
1. **Rendimiento Extremo, Modo 144Hz y Motor Instantáneo:** Aplica rigurosamente `.agent/skills/extreme-multimedia-performance/SKILL.md`.
2. **Lavado de Cara y Rediseño Cinemático (Anti-AI-Slop):** Aplica rigurosamente `.agent/skills/cinematic-ui-facelift/SKILL.md`.
3. **Optimización y Rendimiento de Video (60/120/144 FPS):** Aplica rigurosamente `.agent/skills/flutter-performance/SKILL.md`.
4. **Mejora de UI y Layout Adaptativo:** Aplica `.agent/skills/adaptive-layout/SKILL.md`, `.agent/skills/widget-composition/SKILL.md`, `.agent/skills/custom-canvas-and-gestures/SKILL.md` y `.agent/skills/motion-and-haptics/SKILL.md`.
5. **Código Limpio y Moderno:** Aplica `.agent/skills/dart3-idioms-and-coding-standards/SKILL.md` y `.agent/skills/async-safety/SKILL.md`.
